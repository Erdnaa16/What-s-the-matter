# Head-Movement Activity: Should / Shouldn't Health Advice

This activity helps pupils choose correct health advice by moving their head left or right in front of a camera.

## Learning focus
- Use **should / shouldn't** to give advice.
- Identify suitable advice for common health problems:
  - fever
  - cough
  - cold
  - stomachache
  - toothache
  - headache

## How it works
1. Open `game.html` in a browser.
2. Click **Start Camera**.
3. Read each question.
4. Tilt head **left** to select the left option.
5. Tilt head **right** to select the right option.
6. Hold that direction briefly to confirm selection.
7. Continue until all 6 questions are completed.

## Question set included
- Fever
- Cough
- Cold
- Stomachache
- Toothache
- Headache

## Teacher notes
- If camera tracking is unavailable, pupils can answer using keyboard arrows:
  - `←` for left option
  - `→` for right option
- Encourage full sentence feedback after each item, for example:
  - "He has a fever. He should drink warm water and rest."
